# Example Cards

Example code mod for **Spheres**.

* **Moon Boots** (Uncommon) - floaty jumps, +1 air jump.
* **Storm Caller** (Rare) - hits chain lightning to the next nearest enemy.
* **Underdog** (Uncommon) - only offered while your team is behind.
* Config option `SparkleJumps` (Harmony patch demo) in `BepInEx/config/com.example.spheres.examplecards.cfg`.
